# Hi, I'm Chris 👋

**Astronomer & Scientific Software / Systems Engineer**

I work at the intersection of **science, software, data, infrastructure and instrumentation**.

My background is in astronomy and observational research, but much of my work has involved building the technical systems around science: scientific software, data-processing tools, Linux infrastructure, containerized services, measurement systems and hardware–software integration.

I especially enjoy problems that require understanding the **whole system** — from data and algorithms through software and infrastructure to the physical instrument.

## Selected projects

### 🔭 [AstroPlanner](https://github.com/kkotysz/astroplanner)

Scientific desktop application for planning astronomical observations.

**Python · PySide6 · Astropy · Astroplan · SQLite · APIs · Docker · local LLMs**

Combines astronomical calculations, target ranking, external catalogues and services, weather data, interactive visualization, telescope integration and optional AI-assisted workflows.

---

### 📈 [lcView](https://github.com/kkotysz/lcView)

Scientific workbench for astronomical light-curve and time-series analysis.

**Python · NumPy · SciPy · Astropy · PySide6 · C · Fortran**

A modernization of research software combining a structured Python application with native legacy numerical engines. Includes DFT analysis, iterative prewhitening, phase analysis, detrending, sigma clipping and automated tests.

---

### 🔐 [WireGuard Web App](https://github.com/kkotysz/wireguard-webapp)

Operational dashboard for monitoring WireGuard infrastructure.

**Linux · Python · Flask · Docker · Gunicorn · Nginx · WireGuard**

A compact infrastructure project combining Linux networking, containerization, reverse proxying, JSON API endpoints and health monitoring.
